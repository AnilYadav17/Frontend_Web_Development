## 🚀 Key Topics Covered

### 1. HTML5 & Web Semantics
- **Document Anatomy**: DOCTYPE declarations, viewport configuration, character sets (UTF-8).
- **Semantic Structure**: `<header>`, `<nav>`, `<main>`, `<article>`, `<section>`, `<aside>`, and `<footer>`.
- **Forms & Native Validations**: Form controls, pattern regex attributes, GET vs POST HTTP methods, multipart encodings.
- **Accessibility & SEO**: WAI-ARIA roles, labels, alt attributes, search engine meta tags.

### 2. Modern CSS3 Layout & Design Systems
- **The Box Model**: Content, padding, border, margin; margin collapsing mechanics and `box-sizing: border-box`.
- **Cascade & Specificity**: `!important` > Inline styles > IDs > Classes/Attributes/Pseudo-classes > Elements.
- **Flexbox Mastery**: Flex containers, axis alignment (`justify-content`, `align-items`), auto margins, flex grow/shrink.
- **CSS Grid Mastery**: 2D grid templates, fractional units (`fr`), `repeat(auto-fit, minmax(...))`, grid areas.
- **Responsive Web Design**: Mobile-first media queries, fluid typography with `clamp()`, custom properties (variables).

### 3. Bootstrap 5 Toolkit
- **12-Column Responsive Grid**: Breakpoints (`xs`, `sm`, `md`, `lg`, `xl`, `xxl`), container types, row-col gutters.
- **Utility Classes**: Spacing (`m-*`, `p-*`), flex utilities, typography, background & text colors.
- **Components**: Navbars, cards, modals, accordions, alerts, tables, and form validation states (`was-validated`).
